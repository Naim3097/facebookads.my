# Creative showcase images (Free Audit landing page)

The `/free-audit` page shows a gallery of Izzad's real creative work as proof.

## Drop images here

Name them `01.jpg` … `12.jpg` (jpg, png, or webp all work — keep the `01`–`12` numbers).
Each maps to a tile in the gallery and to a category:

| File | Category shown under |
|------|----------------------|
| 01, 06, 10 | Product Ads |
| 02, 07, 12 | Social & Reels |
| 03, 08 | Carousel |
| 04, 09 | Lifestyle |
| 05, 11 | Effects |

Recommended: portrait/vertical creatives (4:5 or 9:16) look best, ~1080px wide.

**Until you add them**, each tile shows a branded gradient placeholder with its
label — the page still looks intentional, just swap in real work when ready.

## Founder portrait

Save Izzad's portrait as `public/izzad-portrait.jpg` (the black-and-white
mugshot). It appears in the hero and the "creative lead" section. If the file is
missing, it gracefully falls back to an "II" monogram.
